# 23ECE383 System Design Project Report: 8-Phase Divide-by-Two Frequency Divider

> **Status of this document.** The numbers below come from ngspice runs of `spice/divider_baseline_cal.cir` on a
> *generic LEVEL=1 180 nm deck* (`spice/models/cmos180.mod`), regenerated by `scripts/analyze_baseline.py`,
> `scripts/run_pvt_matrix.py` and `scripts/build_reports.py`. They are **not foundry (gpdk045 / TSMC) results**. The
> Cadence gpdk045 results replace the tables in Sections 2-6 when that run is finished. Corners are *synthetic*
> (VTO shifted by 50 mV and KP scaled by 15 percent), not PDK corners.

## 1. Design specification and topology
Reference design: Kuo et al., "A Compact Multiphase Divide-by-Two CMOS Frequency Divider", IEEE MWTL 35(5), 2025.
Four cascaded differential D-latches, driven by CK / CKb, with alternating cross-connections
Q1b to D2, Q2 to D3, Q3b to D4, Q4 to D1b. Each latch: sample pair M1/M2, hold pair M3/M4, clock switches M5 (CK) and
M6 (CKb), tail M7, loads R1/R2.

| Item | Value used |
|---|---|
| Supply | 1.8 V |
| M1-M6 | W/L = 0.9 um / 0.18 um |
| M7 (tail) | 1.8 um / 0.36 um, gate bias 1.2 V |
| Loads R1 = R2 | 5 kOhm |
| Output load | 30 fF on each of the 8 outputs |
| Clock | 1.4 GHz, 50 ps edges, CKb = CK shifted by half a period |

**Deviation from the paper's values, and why.** With the paper's R = 1.5 kOhm, a 0.9 V tail bias and no output loading, the
simulated circuit did not divide: Q and Qb of each latch sat at the same voltage (the cross-coupled pair has too little gain,
gm x R below 1, to hold state) and the outputs followed the clock. R = 5 kOhm, a 1.2 V bias and a 30 fF load were found by
a sweep and make it divide. A larger load (40 fF or more) made division fail again. A start-up condition (`.ic` with `uic`)
is required, otherwise the symmetric state may persist.

## 2. Functionality and 8-phase transient analysis (10 marks)
Measured from the waveform (`results/baseline_cal_tran.txt`), not assumed:

| Quantity | Result |
|---|---|
| Input frequency | 1.400 GHz |
| Output frequency | 700.00 MHz (division ratio 2.0000) |
| Output swing (single-ended) | 0.79 V to 1.79 V |

Phase of each output relative to the Q1 rising edge:

| Output | Phase (deg) |
|---|---|
| V(Q1) | 0.00 |
| V(Q2) | 62.38 |
| V(Q3B) | 89.98 |
| V(Q4B) | 152.38 |
| V(Q1B) | 180.00 |
| V(Q2B) | 242.38 |
| V(Q3) | 269.98 |
| V(Q4) | 332.38 |

Adjacent phase steps (deg): [62.38, 27.6, 62.4, 27.62, 62.38, 27.6, 62.4, 27.62]. The ideal is 45 deg for every step. The measured steps alternate between about
27.6 and 62.4 deg, so the **maximum step error is 17.4 deg**. The paper reports
phase error within 3.75 deg on silicon; this simulation does not reach that. Figure: `results/plots/baseline_8phases.png`,
`results/plots/baseline_phase_error.png`.

*Why the steps are uneven.* The outputs come in four pairs. Inside a pair the offset is a = 360 x t_pair x f_in, where t_pair is the
delay between the two edges triggered by the same clock edge, and the next pair starts 90 deg later, so the steps alternate between
a and 90 - a. Here a = 27.6 deg, which corresponds to t_pair = 55 ps (this is the delay between internal
edges and is not the same quantity as the clock-to-output delay in Section 4). Equal 45 deg steps need a = 45 deg, i.e.
t_pair = T_CK / 8 = 89 ps, so the latch is faster than that condition requires. Adding load capacitance to slow it moved the steps in
the right direction in some runs, but at 40 fF and above the divider stopped dividing, so 45 deg was not reached.

## 3. Power calculation (5 marks)
P = VDD x I_avg, with I_avg the time-average of the supply current over 11 whole output periods
after start-up (trapezoidal integration of `i(Vdd)`):
I_avg = 0.823 mA, so **P = 1.482 mW** at 1.8 V. (The paper reports 2.34 mW on silicon for the
fabricated circuit; this simulated circuit uses a different bias and load, so the values are not expected to match.)

## 4. Delay calculation (5 marks)
Measured clock-to-output delay: for each rising CK edge (50 percent point), the time to the next rising edge on any of the
eight outputs (each at its own mid-swing level), averaged: **110.0 ps**.

First-order cross-check with the Elmore model of the paper (t = 4RC with R1 = R/2): using the load resistor
R1 = 5 kOhm and an assumed node capacitance of about 35 fF (30 fF load plus roughly 5 fF of device capacitance, an
assumption), 0.69 x R1 x C is about 121 ps, the same order as the measured 110 ps. This is a consistency
check, not a validation of the 8C / (R/2) capacitance count, which depends on the PDK's device capacitances.

## 5. Power-delay product (5 marks)
PDP = P x t_d = 1.482 mW x 110.0 ps = **163.1 fJ** (1 mW x 1 ps = 1 fJ).

## 7. Physical layout and DRC (5 marks)
**Not completed in this repository.** The earlier `layout/divider_core.gds` is an empty placeholder (it contains only a
cell name), so it shows no devices and no DRC result. The layout is being done in Cadence Virtuoso on gpdk045; the DRC/LVS
reports and the layout screenshot go here. Layout approach taken from the paper: two-finger unit transistors sharing
diffusion, M7 beside the clock switches, symmetric clock routing with equal wire lengths.
